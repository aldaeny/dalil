# دليل — Dalil

**دليل (Dalil)** هو تطبيق ويب متجاوب وثنائي اللغة (عربي RTL / إنجليزي LTR) لاستكشاف المدن والأماكن الحيوية في العراق (بغداد، أربيل، البصرة، النجف، كربلاء) عبر قاعدة بيانات محلية مدمجة (`SQLite`).

## الفئات الرئيسية
1. **المطاعم (Restaurants)** — مطاعم عراقية وعالمية، مسكوف، مشويات، ومطاعم عائلية.
2. **الكافيهات (Cafes)** — مقاهي مختصة، مقاهي تراثية، ومساحات عمل ودراسة.
3. **محطات الوقود (Gas Stations)** — أنواع الوقود المتوفرة (عادي، محسن، سوبر، غاز LPG، ديزل)، خدمة 24 ساعة، وتحديث حالة الازدحام من المجتمع.
4. **الأماكن الترفيهية (Entertainment)** — متنزهات، كورنيش، مدن ألعاب، صالات بولينغ وسينما.
5. **الأسواق (Markets)** — أسواق شعبية وتراثية، كتب وقرطاسية، وهايبرماركت.
6. **المولات (Malls)** — مجمعات التسوق الكبرى مع تفاصيل الطوابق والمحلات والمواقف.

## المزايا التقنية
- **Next.js 15 (App Router) + TypeScript + Tailwind CSS v4**
- **قاعدة بيانات SQLite مدمجة (`node:sqlite`)** تُنشأ وتُعبّأ تلقائياً في `data/dalil.db` عند أول تشغيل
- **خريطة تفاعلية مدمجة** تدعم السحب والتكبير/التصغير وعرض بغداد (نهر دجلة، الجسور، الأحياء) وخريطة العراق، مع اختيار الإحداثيات عند إضافة مكان جديد
- **حساب حالة "مفتوح الآن"** وفق توقيت العراق المحلي (`Asia/Baghdad`)
- **تقييمات الزوار، المفضلة، وتحديثات محطات الوقود المباشرة**

## التشغيل محلياً
```bash
npm install
npm run dev
```
ثم افتح المتصفح على `http://localhost:3000`.
